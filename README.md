# 台灣標案查詢系統

純前端標案查詢工具，部署於 GitHub Pages，零後端。

## 資料來源
- API：`pcc-api.openfun.app`（由 g0v 社群維護，CORS 開放）
- 原始資料：行政院公共工程委員會 `web.pcc.gov.tw`

## 功能
- 🔍 關鍵字搜尋標案
- 🏛️ 依機關查詢
- 📅 依日期瀏覽
- 📋 標案詳情（含金額、廠商、聯絡資訊）
- ✅ 決標查詢
- 🏷️ 自訂常用關鍵字（儲存在 localStorage）
- 📑 分頁瀏覽

## 授權聲明
本工具資料來源遵循公共工程委員會著作權聲明，僅供查詢參考用途。
